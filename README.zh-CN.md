# Profit Atlas

Profit Atlas 是一个强调证据边界的小型研究插件，提供两个不同的入口：

| 从哪里开始 | 使用哪个 skill | 回答什么问题 |
|---|---|---|
| 行业或产业链 | [`industry-profit-pool-research`](skills/industry-profit-pool-research/) | 利润集中在哪里、为什么，以及哪些外部创业切入点可信？ |
| 具体企业 | [`company-value-chain-review`](skills/company-value-chain-review/) | 企业靠什么活，以及价值通过哪条经营主链变成收入和现金？ |

两个 skill 可以单独使用，也可以组合使用。它们放在同一个仓库里，但保持独立，因为行业利润分布和企业经济性所需的证据、比较口径和输出结构不同。

[English README](README.md)

## 安装

克隆或下载本仓库，把 `skills/` 下需要的目录加入兼容智能体的 skill 目录即可。如果希望行业问题和企业问题能够自动分流，建议同时安装两个。

仓库根目录还提供 [`plugin.json`](plugin.json)，供支持便携式 agent plugin 的客户端识别。

## 直接用自然语言提问

skill 的描述已经为自动触发设计。例如：

- “研究中国游戏行业的利润池，并找出有进入权的创业切入点。”
- “分析比亚迪本质上靠什么活，以及价值怎样变成收入和现金。”
- “比较腾讯、网易和三七互娱的商业模式与利润发动机。”

如果想明确指定入口，可以直接写 skill 名：

- “使用 `industry-profit-pool-research` 研究汽车产业链。”
- “使用 `company-value-chain-review` 复盘美团。”

## 两个 skill 怎样配合

做行业研究时，行业 skill 会按产业角色或商业模式选择代表企业，用企业数据验证利润池判断；这不等于对每家公司做完整复盘。

做企业研究但又需要行业背景时，可以先运行行业 skill，再由企业 skill 汇总两层结果：

1. 企业经济性：谁付钱、为何付钱、收入与利润来源、成本和风险；
2. 价值到现金的经营主链：真正决定收入、成本、风险和信任的少数环节。

## 证据边界

- 企业会计收入不能自动与行业销售额比较。
- 收入占比不能证明利润贡献。
- 毛利润、营业利润、净利润和现金流必须区分。
- 计算与推断要明确标注；未披露的分部利润不能编造。
- 创业机会从外部痛点、预算、进入权、防御性和经济性出发。AI 只被判断为核心能力、增强手段、普通功能或不必要，不预设为答案。
- 行业专项模块用于提高提问覆盖，不是回答该行业的前提。没有专项模块的行业使用通用流程，并明确记录缺失证据。

Profit Atlas 是研究框架，不构成投资建议；做出财务或经营决策前，请独立核验证据。

## 仓库结构

```text
skills/
  industry-profit-pool-research/
  company-value-chain-review/
evals/
examples/
plugin.json
```

[`examples/`](examples/) 中包含一份完整的游戏行业研究，以及汽车行业通用性测试说明；[`evals/`](evals/) 中是触发和边界测试。

## 贡献与测试

修改时应保留两个 skill 的职责边界，并为行为变化增加评测案例。只有当多次真实测试反复暴露通用流程遗漏的、稳定的行业特有问题时，才值得新增行业专项模块。

提交前请验证 front matter、检查所有引用资源、重跑相关评测，并扫描仓库中的私人路径或凭据。
